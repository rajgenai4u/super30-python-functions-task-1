# Super 30 - Python Functions Basics

This repository contains exercises and practical implementations focusing on core Python function concepts, reusability, and foundational logic building as part of the Super 30 program.

## 🎯 Learning Objectives

- Master function declaration using `def`, parameters, default arguments, and return values.
- Practice positional vs. keyword arguments.
- Understand local vs. global scope and string cleaning technique for text analysis.
- Differentiate between displaying values with `print()` and returning values with `return`.

---

## 📑 Notebook Breakdown (`Functions_basics.ipynb`)

The notebook covers the following implementations:

| Function / Topic | Description |
| :--- | :--- |
| **`add_numbers`** | Prompts user inputs to return the sum of two numbers. |
| **Basic Calculator** | Interactive menu providing addition, subtraction, multiplication, and zero-check division (`add`, `subtract`, `multiply`, `divide`). |
| **`is_even_add`** | Determines whether an integer is even or odd using modulo operators. |
| **`find_largest`** | Finds the largest of three numbers using conditional logic without using built-in `max()`. |
| **Factorial Iterative & Recursive** | Calculates factorials using both an iterative loop (`calculate_factorial`) and recursion (`factorial`). |
| **`is_prime`** | Checks if an integer is a prime number. |
| **`calculate_discount`** | Demonstrates default parameters (10% default discount rate). |
| **`calculate_sum`** | Sums a list of numbers without using built-in `sum()`. |
| **`count_vowels`** | Iterates over strings to count total uppercase and lowercase vowels. |
| **`is_palindrome`** | Normalizes string inputs (stripping non-alphanumeric characters and lowering case) to test for palindrome symmetry. |
| **`student_profile`** | Illustrates positional and keyword argument passing. |
| **`print` vs `return` Conceptual Comparison** | Practical code demonstration showcasing why returning values enables functional chaining (e.g., tax calculation) while `print` returns `None`. |
